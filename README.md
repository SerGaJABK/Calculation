# Calculation
Калькулятор на Qt C++ выполняет базовые операции (+, -, *, /), извлечение корня, смену знака, обрабатывает ошибки и поддерживает клавиатуру. Результаты вычислений сохраняются в history.txt. Логика вынесена в отдельный класс Calculation, взаимодействие через сигнал calculation(QString). Проект демонстрирует разделение UI и бизнес-логики в Qt.
