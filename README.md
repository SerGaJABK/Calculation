# Калькулятор на Qt / C++

Простое приложение-калькулятор с графическим интерфейсом, реализованное на C++ с использованием фреймворка Qt. Поддерживает базовые арифметические операции, работу с клавиатурой и сохраняет историю вычислений в файл.

---

## 🚀 Функциональность

- Базовые операции: **сложение (+), вычитание (-), умножение (\*), деление (/)**
- Извлечение **квадратного корня (√x)**
- **Смена знака (+/-)**
- Ввод чисел с плавающей точкой (запятая)
- Очистка поля ввода (C) и удаление последнего символа (←)
- Обработка ошибок:
  - деление на ноль
  - пустое выражение
  - некорректный ввод (соседние операторы)
- **Поддержка клавиатуры**:
  - цифры `0–9`
  - операторы `+`, `-`, `*`, `/`
  - запятая (`.`, `,`)
  - `Backspace` (удаление символа), `Delete` (очистка)
  - `Enter` / `Return` (вычисление)
- **Сохранение истории** вычислений в файл `history.txt` (в корневой папке проекта)

---

## 🧰 Технологии

- C++17
- Qt 5 / Qt 6 (модули Core, Widgets, GUI)
- Сборка через `qmake`
- Стилизация через CSS (файл `style.css`)

| Файл                | Назначение |

| `main.cpp`          | Точка входа, загрузка стилей |

## ⚙️ Сборка и запуск

### Используя Qt Creator
1. Откройте файл `untitled26.pro` в Qt Creator.
2. Настройте комплект (Kit) под вашу версию Qt и компилятор.
3. Нажмите **Run** (Ctrl+R).

### Из командной строки
```bash
qmake untitled26.pro
make
./untitled26        # Linux / macOS
untitled26.exe      # Windows
